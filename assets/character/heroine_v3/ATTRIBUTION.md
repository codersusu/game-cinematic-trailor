# Original expedition heroine — v3

Original adult adventure heroine designed for The Last Observatory. The imagegen concept and exact prompt are saved in `concept.png` and `concept-prompt.md`. No downloaded Lara Croft model or game asset is included.

Generated with Meshy 7 via the authorized account API on 2026-09-11: Ultra geometry, unremeshed master, 8K base color, PBR surface maps, A pose. Actual master: 3,024,348 triangles; 8,192 × 8,192 base color and two 4,096 × 4,096 surface images. See `generation-settings.json` and `master-stats.json`.

The model was generated for this project under [Meshy Terms of Service](https://www.meshy.ai/terms-of-use), particularly §§3.1–3.2 concerning output and incorporated rig/animation service assets. It is not a Poly Haven/CC0 asset. Credit: **Original heroine • Meshy 7 Ultra**. Blender material, rig and animation adaptations are recorded in the revision notes.

[Meshy Image to 3D documentation](https://docs.meshy.ai/en/api/image-to-3d) · [Rigging documentation](https://docs.meshy.ai/en/api/rigging).

Temporary signed service URLs and credentials are excluded from the public project. Model outputs are retained locally because Meshy API storage is temporary.
