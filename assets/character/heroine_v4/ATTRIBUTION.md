# Microsoft Rocketbox Female Adult 04

Source: https://github.com/microsoft/Microsoft-Rocketbox

Copyright Microsoft Corporation. MIT license; see included `LICENSE.md`. Pinned upstream paths and checksums are recorded in `acquisition-manifest.json`.

Downloaded FBX and texture assets are unchanged. Production modifications are generated by `scripts/heroine_motion_v4.py` and `scripts/heroine_look_v4.py`: native clip rest-pose conversion and sequencing, whole-character floor correction, rebuilt Cycles materials, hair alpha, normal maps, subtle skin subsurface scattering, eye shading, subdivision, instrument gaze, blinks, and facial performance keys.

Character inspection: 5,170 vertices, 80 imported bones, 175 facial morphs (52 ARKit channels included). All 80 bone names match the four downloaded motion rigs. The source clips' differing rest poses are converted during integration; matching names alone are insufficient. Final visual validation is tracked by the V4 production documentation.

The original acquisition used Blender with auto-execution disabled; no downloaded Python was run. `inspection.json`, `motion-inspection.json` and `facial-proof.json` record the source evaluation. `UPSTREAM_README.md` preserves Microsoft's repository documentation separately from this project's README.
